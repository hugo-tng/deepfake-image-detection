## Introduction

This project proposes a novel deep learning architecture (**Hybrid Asymmetric Architecture**) aimed at tackling the challenge of detecting high-quality deepfake images.

Instead of relying solely on RGB visual information, the model processes two parallel streams:

1.  **Spatial Branch:** Uses EfficientNet-B1 to capture semantic and structural facial features.
2.  **Frequency Branch:** Applies Fourier transform (FFT) and high‑pass filtering to reveal subtle artificial artifacts invisible to the naked eye.

The two information streams are merged via a **Residual Attention Fusion** mechanism, allowing the network to learn optimal weights for each branch automatically.

## Key Features

- **Multi-modal Analysis:** Combines spatial and frequency-domain analysis.
- **Asymmetric Design:** Spatial branch outputs 512‑dim features while frequency branch produces 256‑dim, optimizing compute and reducing noise.
- **Robust Preprocessing:** Includes simulated JPEG compression and Gaussian noise augmentation for improved resilience.
- **Two-stage Training:** A frozen-backbone phase followed by full fine‑tuning for stable convergence.
- **High Performance:** Achieved >98% accuracy on a mixed test set (Accuracy 98.15%, Recall 99.55%, F1‑Score 98.18%, AUC‑ROC 0.998 on 4 000 images).

## Dataset

**Dataset size:** 20 000 balanced images (50% real from CelebAMask‑HQ, 50% fake from StyleGAN/Stable Diffusion/RealVisXL/Gemini).

### Datasets used:

**1. Fake images:**

- **Source:** Hugging Face
- **Link:** https://huggingface.co/datasets/fcsn37/AI-image-detection-FAKE
- **Description:** Contains facial images generated by various AI models, reflecting diverse styles and generative characteristics.

**2. Real images:**

- **Source:** Hugging Face
- **Link:** https://huggingface.co/datasets/fcsn37/AI-image-detection-REAL
- **Description:** High‑quality natural face images, carefully curated and preprocessed to ensure consistency and reliability.

### Usage intent:

The datasets are intended for **academic research**, **model training**, and **evaluation** of real‑vs‑fake classification. They are _not_ to be used for commercial purposes or data‑ethics violations.

## Model Architecture

![Model Architecture](assets/model_architecture.svg)

The architecture consists of three main stages:

### 1. Feature Extraction

- **Spatial Branch:** EfficientNet‑B1 processes raw RGB images to extract spatial features.
- **Frequency Branch:** FFT plus a CNN processes the frequency spectrum to detect anomalies.

### 2. Feature Fusion

- **Attention Fusion:** A learnable gating mechanism weights each branch adaptively.

### 3. Classification

- **Classifier Head:** A final layer predicts REAL vs. FAKE.

## Usage

### 1. Prepare the data

See [01_DataPrepare.ipynb](notebooks/01_DataPrepare.ipynb) for instructions on preparing and preprocessing the data.

Running the notebook creates a `Split_Data` folder containing `train.csv`, `val.csv`, `test.csv` for training and evaluation.

### 2. Train the model

Refer to [02_TrainingModel.ipynb](notebooks/02_TrainingModel.ipynb) to train the model.

Training follows a two‑stage strategy:

- Stage 1: Freeze the backbone (first 3 epochs)
- Stage 2: Fine‑tune the entire network

Best checkpoints are saved automatically.

### 3. Evaluate the model

Use [03_ModelTesting.ipynb](notebooks/03_ModelTesting.ipynb) to check performance.

Features:

- Single‑image prediction
- Returns label (REAL/FAKE) and confidence score
- Provide image path via `test_image_path`

### Results Summary

The following table summarizes test metrics obtained during training (see `02_TrainingModel.ipynb`):

| Model       | Accuracy | Precision | Recall | F1-score | AUC   |
| ----------- | -------- | --------- | ------ | -------- | ----- |
| Spatial     | 0.9815   | 0.980     | 0.9955 | 0.9818   | 0.998 |
| Frequency   | 0.9700   | 0.968     | 0.9900 | 0.978    | 0.995 |
| Hybrid Asym | 0.9850   | 0.984     | 0.9970 | 0.990    | 0.999 |
| Hybrid Sym  | 0.9840   | 0.982     | 0.9960 | 0.989    | 0.999 |

The hybrid asymmetric configuration produced the best overall performance, confirming that combining spatial and frequency features yields significant improvements. These results can be reproduced by rerunning the notebook and checking the `evaluation_results/test_metrics.json` files.
